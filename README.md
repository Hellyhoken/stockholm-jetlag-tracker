# stockholm-jetlag-tracker

HTML app for tracking excluded areas when playing Jet Lag: The Game in the Stockholm area.

Should be quite easy to adapt for playing in another area by changing the following lattitude and longitude values to include your area:
```javascript
const SOUTH = 58.88, WEST = 17.31, NORTH = 59.86, EAST = 18.313;
```
If you don't mind playing without the stations marked on the map you don't even have to do this. Just open and track away!
